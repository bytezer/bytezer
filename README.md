### Projects

#### 🛵 Altoke Shop

Altoke Shop is an e-commerce platform that enables customers to order products from a variety of local restaurants and stores for home delivery. It streamlines the shopping and delivery process by offering a centralized, user-friendly interface to browse, order, and track products from multiple vendors. The platform was built using React (JavaScript) for the frontend, NestJS for the backend, PostgreSQL for data management, and Firebase Storage for handling media assets.
